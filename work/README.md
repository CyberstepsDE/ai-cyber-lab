# work/: your own work

Everything you create in the lab goes here: `WORK_LOG.md`, `scope.yaml`, `evidence/` and
`reports/`. Git ignores this folder (only this README is part of the repository), so:

- `git pull` brings new practice files without touching your work;
- nothing in here is ever pushed anywhere;
- deleting the lab folder deletes your work. Copy `work/` somewhere safe if you want to keep it.

The agent creates the files and subfolders the first time it needs them.
