# AI Cyber Lab

Practice files for the AI sessions of the Cybersteps cybersecurity program, Module 4.

Everything here is synthetic: made up for practice, not taken from a real network or a real customer. IP addresses come from the ranges reserved for documentation (RFC 5737) and names from reserved domains (RFC 2606).

## Samples

| File | What it is |
|---|---|
| `samples/auth.log` | 66 lines of an SSH server log from one night on a server called `web01`. Used to compare a chat assistant with an agent and to check the agent's answer. |
| `samples/tickets/` | Three customer support tickets for an AI summary. One of them hides an instruction for the AI (indirect prompt injection). |

## Get the files

```bash
git clone https://github.com/CyberstepsDE/ai-cyber-lab.git
cp -r ai-cyber-lab/samples ~/demo
```
